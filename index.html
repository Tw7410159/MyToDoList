如何取得 Firebase Web 設定？
  1. 前往 Firebase Console → 專案設定
  2. 「一般」頁籤 → 「您的應用程式」→ 建立或選擇 Web App
  3. 複製 apiKey、appId（其餘已預設）填入下方
  4. 到「Authentication → Sign-in method」開啟 Google 登入
  5. 到「Firestore Database」建立資料庫
